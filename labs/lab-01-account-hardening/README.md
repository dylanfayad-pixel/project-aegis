# Lab 1 – AWS Account Hardening & Security Baseline

## Executive Summary

This lab established a secure AWS foundation by configuring account security controls, implementing IAM best practices, and creating cost monitoring.

---
## Objective

Build a secure AWS environment following AWS Well-Architected Security best practices.

---

## Services Used

- AWS IAM
- AWS Budgets
- Billing & Cost Management

---

## Tasks Completed

- Created AWS account
- Enabled MFA on the root account
- Created an Administrators IAM group
- Created an IAM administrator user
- Logged in using the IAM administrator account
- Configured a monthly AWS budget with alerts

---

## Security Best Practices Implemented

- Root account protection
- Multi-Factor Authentication (MFA)
- IAM groups
- Principle of Least Privilege
- Cost governance

---

## Lessons Learned

This lab demonstrated why AWS recommends using IAM users for daily administration while reserving the root account for emergency or account-level tasks.

---

## Resume Bullet

Built and secured a new AWS environment by implementing MFA, IAM administrative access through groups, and AWS Budgets with automated cost alerts following AWS security best practices.
