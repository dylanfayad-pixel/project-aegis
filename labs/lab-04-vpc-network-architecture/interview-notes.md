# Interview Notes

## What is a VPC?

A Virtual Private Cloud (VPC) is an isolated virtual network inside AWS.

---

## Public vs Private Subnets

Public subnets communicate directly with the Internet.

Private subnets do not.

---

## What belongs in a Public Subnet?

- Web Servers
- Load Balancers

---

## What belongs in a Private Subnet?

- Databases
- Internal Applications

---

## Security Groups vs Network ACLs

Security Groups protect instances.

Network ACLs protect subnets.
