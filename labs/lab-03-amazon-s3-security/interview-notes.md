# Interview Notes

## What is Amazon S3?

Amazon S3 is AWS's object storage service that stores data as objects inside buckets.

---

## Bucket vs Object

Buckets are containers.

Objects are the individual files stored inside buckets.

---

## Bucket Policy vs IAM Policy

IAM policies are identity-based.

Bucket policies are resource-based.

AWS evaluates both together.

---

## What happens if an Explicit Deny exists?

Explicit Deny always overrides Allow.
